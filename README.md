# Emotion Detector – Watson NLP Integration

A Flask web application that uses IBM Watson NLP to detect emotions in text.

## Features
- Detects anger, disgust, fear, joy, and sadness.
- Returns the dominant emotion.
- Handles blank input and API errors gracefully.

## Technologies
- Python, Flask, Requests, IBM Watson NLP API, Unittest, Pylint.
